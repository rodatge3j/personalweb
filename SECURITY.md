# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub instead:
**[Report a vulnerability](https://github.com/umutxyp/Personal-Website/security/advisories/new)**

Include what you found, how to reproduce it, and what an attacker could do with it. You will get an answer as soon as possible, and the fix will be published together with a security advisory that credits you, unless you prefer otherwise.
